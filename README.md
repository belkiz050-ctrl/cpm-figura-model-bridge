# CPM + Figura ModelBridge 2.0.8

Для Minecraft 26.3 и Fabric. В этой версии заменена иконка мода: новая квадратная аватарка вдохновлена предоставленным референсом — фиолетовое неоновое свечение, блочная Minecraft-персонажка с белыми волосами и схематичный wireframe-акцент модели. Сохранены тематические кнопки режимов и исправление рендера Figura.

## Совместимость

- Minecraft 26.3, Java 25+
- Fabric Loader 0.19.5+
- CPM Fabric 0.6.27e или новее
- NoFigura Fabric 0.1.6.10+26.3

## Установка

1. Удали старые JAR ModelBridge (2.0.4–2.0.7) из папки `mods`.
2. Помести `cpm-figura-model-bridge-2.0.8.jar` в `mods`; CPM и Figura оставь установленными.
3. Запусти игру. Новая иконка будет видна в списке модов Fabric/загрузчика.

Если после установки появится ошибка, приложи новый `latest.log`.
